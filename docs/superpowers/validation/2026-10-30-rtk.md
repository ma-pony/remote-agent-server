settings persistence; semantic version ordering; daily checks and hourly retry;

four failures covered duplicate Claude/Codex native hooks, prefixed rewrites, and a missing
executable inside an existing version directory. Those regressions pass after correction.

- Projection now replaces standalone selected native RTK hooks with the stable managed
  gate without editing source files or saved selections. Hermes also replaces its native
  `rtk-rewrite` plugin; unrelated hooks and plugin registrations remain intact.
- Binding scans executable positions while preserving original shell text, including
  environment assignments, `cd`, compound commands, and supported process wrappers.
  Tests exercise the actual gate, preserve `ask`/`deny` decisions, and execute a shell
  fixture with an unavailable PATH to verify absolute binding, cwd, environment, and
  literal argument preservation. Unsupported shell control constructs and attached glob
  parentheses retain the original. Permission-only `ask` responses remain intact; when
  a rewrite cannot be safely bound, the confirmation request survives without forwarding
  the unbound rewrite.
- Reinitialization self-tests the current executable. Missing, non-executable, and corrupt
  files are repaired only after candidate validation. Healthy same-version files retain
  their inode. Failed or cancelled replacement preserves the existing file, enabled state,
  and rollback target; staging is cleaned.
