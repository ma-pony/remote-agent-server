# 管理台体验审核与优化

日期：2026-10-14

本轮使用 UI UX Pro Max、Impeccable、copywriting 和 copy-editing，检查管理台的通用导航与页面组件，以及登录、智能体列表、项目环境列表、会话列表与详情、接入端点、用量看板、用量分析和运行设置。沿用现有 shadcn/Radix 组件、语义颜色和中英文 `text(...)` 模式。

## 已修复的问题

| 问题 | 调整后的行为 | 验证方式 |
| --- | --- | --- |
| 列表请求失败后仍显示骨架屏，缺少恢复入口 | 智能体、项目环境、会话、接入端点列表明确显示加载错误和重新加载按钮；重试时清除旧错误 | 四类列表失败与重试交互测试 |
| 项目环境检查失败与智能体列表失败混在一起 | 分开呈现环境检查错误，已加载的智能体仍然可见 | 独立请求失败测试 |
| 懒加载页面时整个导航一起消失 | 导航保持可用，仅页面内容显示加载状态 | 未完成的懒加载路由测试 |
| 侧栏固定显示“已连接”，但没有实时状态依据 | 改为浏览器会话说明；接入任务详情正确关联接入端点导航 | 导航状态测试、桌面检查 |
| 错误网址静默跳转，登录失败原因不够清楚 | 增加页面不存在提示和返回入口；区分令牌无效、失效与网络错误 | 路由、登录、语言切换测试 |
| 剪贴板不可用或复制内容已变化时可能误报反馈 | 只有当前复制请求成功才显示已复制；失败时提供手动复制说明；内容变化和卸载会使旧请求反馈失效 | 拒绝权限、无剪贴板接口、成功重试、旧请求成功或失败的四种竞态场景 |
| 清空存储保留时间会被转换成 0 | 空值标为无效，不能保存；明确输入 0 仍可关闭自动清理 | 空值与零的交互测试 |
| 设置读取失败显示“保存失败”，并继续显示骨架屏 | 区分加载失败与保存失败，提供重新加载；保存期间禁用输入 | 设置读取、重试和校验测试 |
| 移动端会话输入区遮挡历史内容 | 小屏输入区随正文滚动，桌面保留底部吸附；长输入、回复和模型名约束在内容宽度内 | 375px 英文会话页面检查 |
| 看板标题、筛选区与指标卡重复占用空间 | 缩短说明，压缩筛选区，以同一分区呈现概要指标；为空会话筛选提供扩大范围或清除 Agent 筛选的入口 | 看板交互测试、桌面与小屏检查 |
| 用量分析将未上报和来源冲突统称为部分数据 | 分别显示未上报、来源冲突、部分和完整；保留模型上报与内容估算的区别 | 用量页面回归测试 |
| 页面标题操作区、搜索焦点、分页和标签页缺少一致处理 | 操作区按宽度换行；搜索焦点可见；分页报告项目范围；标签页可横向滚动；触屏输入与选择控件扩大点击区域 | 通用组件检查、交互回归与小屏检查 |

## 文案与数据说明

- 登录页先说明进入管理台需要什么；自行部署的令牌获取步骤放入可展开说明。
- 首次使用引导说明当前环境状态和下一步操作，删除重复流程口号。
- 错误提示说明失败对象，并提供重试、返回或手动操作路径。
- 看板继续明确 UTC 自然日、今天尚未结束、缺失上报和完整历史累计用量。单会话总量仍按会话创建时间排列，可能包含筛选日期之外的用量。
- 存储清理说明明确区分会话与执行元数据、Token 统计、原始事件保留策略。
- 本轮调整呈现与交互，没有修改后端用量聚合、执行调度或持久化结构。
